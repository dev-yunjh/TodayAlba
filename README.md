Description
---
오늘도알바는 아르바이트 근무지별 일정 및 급여 관리, 근무일별 메모 기록, 근무지 후기 공유, 커뮤니티 기능을 제공하는 아르바이트 종합 플랫폼입니다.

실제 서비스 출시 및 운영을 목표로 하는 장기 개인 프로젝트로, 초기에는 핵심 기능을 중심으로 MVP를 개발하고, 사용자 피드백과 서비스 운영 경험을 바탕으로 지속적인 기능 개선 및 확장을 진행할 계획입니다.
