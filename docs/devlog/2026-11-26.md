## 3. 주요 설계 결정

- 회원 식별자는 UUID(BINARY(16)), 근무 데이터 식별자는 BIGINT 사용
- JPA 자동 DDL 생성 대신 SQL 기반 스키마 직접 설계
- 근무지 기본 정보와 급여 설정 분리
- JSON 형태의 급여 설정을 개별 컬럼으로 분리
- CHECK 제약조건을 활용한 조건별 필수값 및 NULL 검증
- 급여 산정 방식과 급여 지급 주기 분리
- 급여 조건 및 지급 예정일 스냅샷을 통한 과거 데이터 보존
- 불필요한 BOOLEAN 및 중복 컬럼 제거
- 조회 패턴을 고려한 복합 인덱스 설계
- 생성일 및 수정일은 JPA Auditing에서 관리하도록 설계
- 일일 근무 기록에는 세전 급여, 급여 지급일에는 예상 실수령액을 표시하도록 설계
